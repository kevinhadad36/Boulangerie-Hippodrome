# Boulangerie de l'Hippodrome — site démo

Site vitrine + click & collect réservé aux grosses commandes (événements, entreprises) pour la Boulangerie de l'Hippodrome, 5 rue Joachim du Bellay, 31100 Toulouse.

- Style : reproduit le site Redbrick Coffee (Refero Styles « Scarlet ink editorial on butcher paper »).
- Photos : photos réelles de la boutique issues de la fiche Google.
- Commande : panier en JS, envoi de la demande par e-mail (mailto), minimum de pièces réglable via MIN_PIECES dans index.html.
